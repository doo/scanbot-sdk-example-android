# Scanbot Data Capture Ready-To-Use UI example

This project demonstrates the Scanbot SDK Ready‑To‑Use UI for data capture modules (MRZ, VIN, text pattern, checks, credit cards, document data extraction, and more).

## Requirements

- Latest stable Android Studio
- JDK 17

## How to run

1. Open `scanbot-sdk-example-android/data-capture-ready-to-use-ui-example` in Android Studio.
2. Sync Gradle.
3. Add your license key in `Application`.
4. Run the app on a device or emulator.

## Obfuscation

Minification is disabled in this example and no custom ProGuard/R8 rules are provided. If you enable minification, add your own rules and follow the Scanbot SDK obfuscation guidance from the official documentation.
